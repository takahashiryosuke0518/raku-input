# らくらくにゅうりょくん！

「らくらくにゅうりょくん！」は、プロフィール情報を保存し、Webフォームへボタンひとつで入力できるChrome拡張機能です。

氏名や住所、連絡先、学歴、研究情報など、何度も入力する情報をあらかじめ登録しておくことで、エントリーフォームなどへの入力作業を省力化します。自動入力は利用者が「このページに入力」を押したときだけ、現在開いているタブに対して実行されます。

## 主な機能

- プロフィール情報をChromeのローカルストレージへ保存
- 現在のページにある対応フォーム項目を判定して自動入力
- 姓名、電話番号、メールアドレス、日付・年月などの分割入力に対応
- 標準的なHTMLフォームに加え、一部の旧来型フォームやカスタム入力欄にも対応
- プロフィールをJSONファイルとしてエクスポート・インポート
- 曖昧な項目や入力できない項目をスキップし、フォームを自動送信しない安全寄りの動作

## 保存できる情報

- 基本情報
  - 姓・名
  - 英字姓・英字名
  - カナ姓・カナ名
  - 生年月日・性別
- 連絡先・所在地
  - 電話番号・携帯電話番号
  - メールアドレス
  - 郵便番号・住所・建物名
  - 居住地・帰省先
- 学校・学歴情報
  - 課程・学年・学校名・研究科・専攻
  - 中学校、高等学校、大学、大学院の学校名と在籍年月
  - 最終学歴と卒業・修了状況
- 研究情報
  - 所属研究室・所属期間
  - 研究キーワード・研究概要

## インストール方法

1. このリポジトリをダウンロードまたはクローンします。
2. Chromeで `chrome://extensions` を開きます。
3. 画面右上の「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を選択します。
5. このリポジトリのフォルダーを指定します。

インストール後、必要に応じて拡張機能をツールバーへ固定してください。

## 使い方

1. ツールバーから「らくらくにゅうりょくん！」を開きます。
2. 自動入力したいプロフィール情報を入力し、「保存」を押します。
3. 入力先のWebフォームを開きます。
4. もう一度拡張機能を開き、「このページに入力」を押します。
5. 入力内容を確認してから、Webサイト側の操作でフォームを送信します。

保存値が空の項目、判定が曖昧な項目、無効または読み取り専用の項目は変更されません。

## プロフィールの移行

「プロフィールをエクスポート」を押すと、保存中のプロフィールを `profile.local.json` として書き出せます。別の環境では「プロフィールをインポート」からこのファイルを読み込めます。

エクスポートファイルには個人情報が平文で含まれ、暗号化されません。共有を避け、安全な場所で保管してください。

## プライバシーと権限

- プロフィールは `chrome.storage.local` に保存されます。
- 外部APIや解析サービスへのデータ送信は行いません。
- 自動入力は、利用者がボタンを押した時点のアクティブなタブだけで実行されます。
- 使用する権限は `storage`、`activeTab`、`scripting` です。
- 拡張機能自身が送信ボタンのクリックやフォーム送信を行うことはありません。

## 注意事項・制限

- Webサイトごとにフォームの構造が異なるため、すべての入力欄への対応を保証するものではありません。
- 判定できない項目や、複数の意味に解釈できる項目には入力しません。
- iframe内、Shadow DOM内、Chromeの設定ページやChromeウェブストアなどでは入力できません。
- 独自実装された入力ウィジェットでは、値が反映されない、または見た目が更新されない場合があります。
- 値の変更時には通常の `input` / `change` イベントを発生させます。サイト側の処理がこれらのイベントをきっかけに画面遷移などを行う可能性があるため、初めて利用するサイトでは入力後の動作を確認してください。

## 開発・テスト

実行時・開発時ともに外部パッケージへ依存していません。テストにはNode.js組み込みのテストランナーを使用します。

```powershell
npm test
```

主なファイルの役割は次のとおりです。

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | Chrome拡張機能の設定と権限定義 |
| `popup.html` / `popup.css` | プロフィール入力画面の構造とスタイル |
| `popup.js` | 保存、自動入力、インポート・エクスポートの操作 |
| `profile-storage.js` | プロフィールの正規化と保存形式の管理 |
| `autofill.js` | フォーム項目の判定と値の入力 |
| `content.js` | 保存済みプロフィールを現在のページへ適用 |
| `tests/` | 自動テストと手動確認用フォーム |
